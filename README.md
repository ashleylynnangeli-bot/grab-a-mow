# Grab-A-Mow Marketplace

Grab-A-Mow connects homeowners seeking lawn care with independent lawn professionals serving their area.

## Official links

- Website: https://grabamow.com
- Get started: https://grabamow.com/app
- Support: hello@grabamow.com

## How it works

Homeowners can create lawn-care requests, add property details and photos, and review responses from available professionals. Lawn professionals can create a business profile, select a service area, complete required account setup, and review nearby opportunities as availability expands.

Availability varies by location. This repository provides official public information about Grab-A-Mow Marketplace; private application source code and customer data are not stored here.
